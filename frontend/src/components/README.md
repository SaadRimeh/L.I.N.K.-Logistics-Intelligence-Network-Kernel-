# 🎛️ L.I.N.K. Frontend Components

The `frontend/src/components/` directory contains the tactical user interface modules, 3D geospatial overlays, and command decks that comprise the L.I.N.K. command terminal.

---

## 🧭 Component Inventory

```
frontend/src/components/
├── MapDeckView.jsx             # 3D Mapbox GL vector map & interactive layers
├── ControlPanel.jsx            # Strategic operations panel & domain filters
├── LiveRadarScope.jsx          # 360° tactical sweeping military radar HUD
├── EnergyIntelligenceDeck.jsx  # Energy defense, kinetic strikes & reserve routing
├── DecisionDeck.jsx            # Geopolitical AI analysis & crisis simulation deck
├── EmergencyModal.jsx          # Airspace interdiction & emergency diversion modal
├── TelemetryDossier.jsx        # Selected entity real-time telemetry drawer
└── Navbar.jsx                  # Top navigation, status indicator & HUD toggle
```

---

## 🔍 Detailed Component Specifications

### 1. `MapDeckView.jsx` — 3D Geospatial Engine
- **Dark Vector Canvas**: Built on `mapbox://styles/mapbox/dark-v11` with 3D pitch ($40^\circ$) and smooth pan/zoom controls.
- **Dashed Flight Tracks (`- - - - - - - - - - - -`)**:
  - All active regional flights display full geodesic arcs styled with `line-dasharray: [4, 3]`.
  - Color-coded: `#38bdf8` (Commercial), `#fbbf24` (Cargo), `#c084fc` (Defense / Reconnaissance), `#34d399` (VIP), `#ff2a5f` (Conflict Alert).
- **Single Flight Isolation**:
  - Clicking any aircraft isolates its flight path, automatically concealing all other planes' dashed routes.
  - Re-clicking that aircraft (or clicking anywhere on the map background) restores all dashed routes.
- **Threat & Blast Geometry**: Renders ACLED conflict danger polygons and circular blast radius zones ($45$ km) for struck energy facilities.
- **Airplane Silhouettes**: Rotated SVG airplane silhouettes aligned with real-time compass heading angles.

### 2. `ControlPanel.jsx` — Operations & Routing Hub
- **Domain Selection**: 6 operational domain modes:
  - `MARITIME` (مائي): Tankers, container ships, and port berths.
  - `AIR` (طيران): Regional passenger, international transit, and cargo flights.
  - `DEFENSE` (دفاع واستطلاع 🛡️): Highlights the 7 AWACS, maritime patrol, and electronic surveillance missions.
  - `LAND` (بري): Overland truck convoys, dry ports, and highway corridors.
  - `ENERGY` (طاقة): Oil refineries, LNG terminals, and pipelines.
  - `ALL` (الكل): Consolidated unified digital twin view.
- **Routing Engine UI**: Point-and-click selection for origin and destination nodes with priority selector (`time`, `cost`, `risk`, `balanced`).
- **Scenarios Tab**: Quick triggers for geopolitical crises (Hormuz closure, Airspace interdiction, Turkish lifeline).

### 3. `LiveRadarScope.jsx` — Tactical HUD Radar
- Real-time polar coordinate projection mapping geographic latitude/longitude relative to the Middle East tactical center ($25.5^\circ\text{N}, 49.0^\circ\text{E}$).
- Continuous $360^\circ$ radar beam sweep loop at 60 FPS.
- Concentric range rings calibrated to $200$, $400$, $600$, and $800$ Nautical Miles.
- Target lock mode displaying azimuth, bearing, speed, and emergency status.

### 4. `EnergyIntelligenceDeck.jsx` — Energy Defense & Kinetic Strike
- Comprehensive operational dossier of Ras Tanura, Yanbu, Mina Al-Ahmadi, Das Island, and Ras Laffan.
- **Simulate Kinetic Strike**: Dynamically applies missile damage to a chosen facility, updates map with blast zone polygon, calculates daily export loss, and triggers proactive pipeline diversion proposals.

### 5. `DecisionDeck.jsx` — Geopolitical Command Center
- Evaluates holistic network health and aggregates active hazard counts.
- Displays strategic contingency advice generated by the decision intelligence engine.

### 6. `EmergencyModal.jsx` — Emergency Airspace Diversion
- Pops up automatically when an aircraft intersects an active conflict hazard zone.
- Visualizes the immediate vector turn directive, nearest safe-haven airport, and landing ETA.

### 7. `TelemetryDossier.jsx` — Entity Inspection Drawer
- Slide-in panel displaying real-time telemetry for any selected flight or vessel:
  - Callsign, operator, country, aircraft model / vessel flag.
  - True altitude, ground speed, heading, and transponder squawk code.
  - Quick action button to lock and focus tracking on map.

### 8. `Navbar.jsx` — Global Status Header
- Displays live Neo4j connection health, total nodes, total corridors, active danger zones, and fleet counts.
- One-click network reset button and HUD radar toggle.
